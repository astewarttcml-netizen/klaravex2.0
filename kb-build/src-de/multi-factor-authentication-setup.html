Ein starkes Passwort allein reicht nicht aus. Passwörter werden mehrfach verwendet, durch Phishing abgegriffen, bei Datenschutzverletzungen geleakt und erraten. Die Multi-Faktor-Authentifizierung (MFA) fügt einen zweiten Verifizierungsschritt hinzu — in der Regel einen zeitbasierten Code aus einer App oder eine Push-Benachrichtigung —, der gestohlene Passwörter für Angreifer wertlos macht.

Die Aktivierung von MFA dauert etwa 3 Minuten pro Konto. Es gibt keine andere Sicherheitsmaßnahme mit einem besseren Verhältnis von Zeitaufwand zu Nutzen.

Authenticator-Apps
Welche App sollten Sie verwenden?
Am besten für M365

Microsoft Authenticator

Die richtige Wahl für jede Microsoft-365-Umgebung. Unterstützt passwortlose Anmeldung, Push-Benachrichtigungen und Nummernabgleich zum Schutz vor MFA-Fatigue-Angriffen.

Universell

Google Authenticator

Einfach und zuverlässig für private Konten und Google Workspace. Unterstützt jetzt Cloud-Backup auf das Google-Konto. Keine Push-Benachrichtigungen — generiert 6-stellige Codes.

Am besten für Wiederherstellung

Authy

Die beste Wahl, wenn die Kontowiederherstellung Priorität hat. Synchronisierung über mehrere Geräte, verschlüsseltes Cloud-Backup und Desktop-App. Gut geeignet für Personen, die viele Konten verwalten.

Schritt-für-Schritt-Einrichtung
Aktivieren Sie MFA für die wichtigsten Konten
☁️

Microsoft 365

1

Melden Sie sich unter aka.ms/mfasetup an oder gehen Sie zu Ihrem Microsoft-Konto → Sicherheit → Erweiterte Sicherheitsoptionen.

2

Wählen Sie “Neue Methode zur Anmeldung oder Verifizierung hinzufügen.” Wählen Sie die Authenticator-App.

3

Installieren Sie Microsoft Authenticator auf Ihrem Smartphone. Scannen Sie den auf dem Bildschirm angezeigten QR-Code.

4

Bestätigen Sie die Test-Benachrichtigung auf Ihrem Smartphone, um die Einrichtung abzuschließen.

5

Administratoren: Erzwingen Sie MFA für alle Benutzer in Microsoft Entra (Azure AD) → Sicherheit → Bedingter Zugriff, oder aktivieren Sie die Sicherheitsstandards.

📧

Google / Gmail

1

Gehen Sie zu myaccount.google.com → Sicherheit → Bestätigung in zwei Schritten.

2

Klicken Sie auf “Jetzt starten” und geben Sie bei Aufforderung Ihr Passwort ein.

3

Wählen Sie Authenticator-App aus der Liste (gegenüber SMS bevorzugt). Scannen Sie den QR-Code.

4

Geben Sie den 6-stelligen Code aus der App zur Bestätigung ein und klicken Sie dann auf Aktivieren.

🍎

Apple ID

1

Auf iPhone/iPad: Einstellungen → [Ihr Name] → Anmelden & Sicherheit → Zwei-Faktor-Authentifizierung.

2

Auf dem Mac: Apple-Menü → Systemeinstellungen → [Ihr Name] → Anmelden & Sicherheit → Zwei-Faktor-Authentifizierung.

3

Folgen Sie den Anweisungen, um eine vertrauenswürdige Telefonnummer hinzuzufügen. Apple sendet Bestätigungscodes automatisch an vertrauenswürdige Geräte.

💼

LinkedIn

1

Klicken Sie auf Ihr Profilfoto → Einstellungen & Datenschutz → Anmeldung & Sicherheit → Bestätigung in zwei Schritten.

2

Wählen Sie “Authenticator-App” und klicken Sie auf Einrichten.

3

Scannen Sie den QR-Code mit Ihrer Authenticator-App, geben Sie den 6-stelligen Code zur Bestätigung ein und speichern Sie.

Authenticator-App vs. SMS
Warum die App sicherer ist als eine Textnachricht

SMS-basierte MFA ist weitaus besser als gar keine — aber sie hat bekannte Schwachstellen. Wenn eine Website eine Authenticator-App-Option anbietet, nutzen Sie diese.

Empfohlen

Authenticator-App
  • Codes werden offline generiert — kein Mobilfunknetz erforderlich
  • Immun gegen SIM-Swapping-Angriffe
  • Codes verfallen alle 30 Sekunden
  • Funktioniert im Flugmodus oder bei schlechtem Empfang
  • Schwerer abzufangen als SMS
Akzeptabel — aber schwächer

SMS-Textnachricht
  • Anfällig für SIM-Swap-Angriffe (Angreifer portiert Ihre Nummer)
  • Codes können über Schwachstellen im SS7-Protokoll abgefangen werden
  • Erfordert Mobilfunkempfang
  • Social Engineering kann Ihre Nummer auf einen Angreifer umleiten

Häufige Fragen
FAQ
Was ist, wenn ich mein Smartphone verliere und nicht mehr auf meine Konten zugreifen kann?

Das ist die häufigste Sorge — und sie ist beherrschbar. Die meisten Plattformen stellen bei der Einrichtung von MFA Backup-Codes bereit. Drucken Sie diese aus und bewahren Sie sie an einem sicheren Ort auf. Auch die geräteübergreifende Synchronisierung von Authy hilft. Bei Geschäftskonten kann Ihr IT-Administrator die MFA zurücksetzen. Das Risiko, ausgesperrt zu werden, ist weitaus geringer als das Risiko einer Kontokompromittierung ohne MFA.

Verlangsamt mich MFA bei jeder Anmeldung?

Für die meisten Konten nicht. Sobald ein Gerät als vertrauenswürdig markiert ist, sehen Sie MFA-Abfragen nur noch, wenn Sie sich von einem neuen Gerät oder Browser anmelden oder nach einem längeren Zeitraum. Push-Benachrichtigungen von Microsoft Authenticator dauern etwa 3 Sekunden. Die geringe Unannehmlichkeit ist den Schutz wert.

Wir haben 50 Mitarbeiter. Wie erzwingen wir MFA im gesamten Unternehmen?

Aktivieren Sie in Microsoft 365 die Sicherheitsstandards (kostenlos) oder Richtlinien für bedingten Zugriff (erfordert Azure AD P1, enthalten in M365 Business Premium). Gehen Sie in Google Workspace zu Admin-Konsole → Sicherheit → Bestätigung in zwei Schritten → Erzwingung. Mit beiden Ansätzen können Sie MFA mit wenigen Klicks für alle Benutzer erzwingen, mit einer Übergangsfrist für die Registrierung.

Möchten Sie, dass wir MFA in Ihrem gesamten Unternehmen durchsetzen?

Wir können Richtlinien für bedingten Zugriff oder die Erzwingung in Google Workspace konfigurieren und sicherstellen, dass kein Konto durchrutscht.
