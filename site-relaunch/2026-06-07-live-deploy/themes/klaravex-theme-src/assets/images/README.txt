KLARAVEX THEME — PHOTO GUIDE
==============================

Replace these photos before launch. Upload via WordPress Media Library,
then set via Appearance > Customize > Klaravex Theme.

REQUIRED
─────────────────────────────────────────────
1. hero-bg.jpg (or .webp)
   - Purpose: Hero section background
   - Size: 1920 × 1080px minimum
   - Style: Warm-lit professional in an office environment
     Shallow depth of field, person slightly blurred on right side
     AVOID: server rooms, handshakes, stock smiles, blue LED lighting
   - Current fallback: Unsplash photo-1573496359142 (auto-loaded)

OPTIONAL UPGRADES
─────────────────────────────────────────────
2. engineer-portrait.jpg
   - Purpose: "Your engineer" section / About page
   - Size: 800 × 1000px (portrait orientation)
   - Style: Professional headshot, dark background, serious but approachable

3. team-photo.jpg
   - Purpose: About page header
   - Size: 1600 × 900px
   - Style: Small team, casual office environment

PHOTO SOURCES
─────────────────────────────────────────────
- Unsplash (unsplash.com) — free, no attribution required for commercial use
- Pexels (pexels.com)    — free, no attribution required
- Stocksy (stocksy.com)  — premium, recommended for hero photos

REPLACING VIA CUSTOMIZER
─────────────────────────────────────────────
1. WordPress Admin > Appearance > Customize
2. Klaravex Theme > Hero Section > Background Photo
3. Upload your photo and click "Select"
4. Publish

The theme will automatically apply the correct dark gradient overlay.
