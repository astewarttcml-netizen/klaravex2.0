What makes this hard in production

AI knowledge platforms are easy to demo and hard to operate.

Most never reach steady state because one of three things fails first:

Failure mode 1

The bot leaks confidential content

Permission filter applied after the LLM has already seen the document. Paraphrase + inference leak follows. The DPO never recovers trust.

Failure mode 2

Lifecycle dies on day 90

Validity periods, re-submissions, status transitions — all present at go-live, all silently failing by Q4 because nobody owns escalation when Content Owners stop responding.

Failure mode 3

Mailbox ingestion goes wrong on day one

Default-on mailbox connector ingests personal correspondence at scale. The supervisory authority finds out. The DPIA is opened on a system already in production.

Deep dive · point 3

Resolving the audit-vs-no-copy contradiction.

§7 says: no copy of data-hub PII. §5.3 says: audit-proof logging. The bot's answer contains PII. The audit log retains it. Both clauses cannot be honoured by a single store.

Action log
7 years

Operational accountability

  • Who, what, when
  • Content IDs cited (by ID only)
  • Permission filter hash
  • Latency, outcome flags
  • No answer text
Read log
90 days

Conversational content

  • Query text
  • Answer text
  • User + timestamp
  • Auto-purged daily TTL
  • Bounds PII retention

ADR-0004 · proposal §6.3. Maximum window in which hub PII can appear in a Knowledge-Manager-controlled store: 90 days.

Compliance posture

GDPR. NIS2. BSI C5. Done deliberately, not as boilerplate.

GDPR Art. 28 chain:

visitBerlin (controller) → Klaravex (processor) → Microsoft (sub-processor, EU entity, EUDB).

Sub-processor change notification with 30-day right of objection.

DPIA:

Joint completion in phase 2. Signed before any production data is ingested.

NIS2 / NIS2UmsuCG:

Operated to NIS2 standards regardless of scope. Klaravex is in-scope as supplier.

24 h breach notification to DPO. 4 h initial classification.

BSI C5:

Type 2 attestation within 24 months of go-live. C5-aligned operation from day one.

Full dossier in /compliance/ — DPIA outline, GDPR Art. 28 map, NIS2 scope analysis, BSI C5 control mapping, data residency.
