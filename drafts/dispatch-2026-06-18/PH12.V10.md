```markdown
# Phase12 E2E Testing Instructions

## Test Scenarios

### Scenario 1: User Registration
- **Description**: Verify that a new user can register successfully.
- **Steps**:
  1. Navigate to the registration page.
  2. Enter valid user details (username, email, password).
  3. Click the "Register" button.
- **Expected Result**: User is redirected to the dashboard page with a success message.

### Scenario 2: User Login
- **Description**: Verify that a registered user can log in successfully.
- **Steps**:
  1. Navigate to the login page.
  2. Enter valid credentials (username, password).
  3. Click the "Login" button.
- **Expected Result**: User is redirected to the dashboard page with a welcome message.

### Scenario 3: User Profile Update
- **Description**: Verify that a logged-in user can update their profile information.
- **Steps**:
  1. Navigate to the profile page.
  2. Update user details (e.g., name, email).
  3. Click the "Save" button.
- **Expected Result**: User's profile is updated, and a success message is displayed.

### Scenario 4: User Logout
- **Description**: Verify that a logged-in user can log out successfully.
- **Steps**:
  1. Navigate to the dashboard page.
  2. Click the "Logout" button.
- **Expected Result**: User is redirected to the login page with a logout confirmation message.

### Scenario 5: User Data Deletion
- **Description**: Verify that a logged-in user can delete their account.
- **Steps**:
  1. Navigate to the settings page.
  2. Click the "Delete Account" button.
  3. Confirm the deletion.
- **Expected Result**: User's account is deleted, and they are redirected to the registration page with a confirmation message.

### Scenario 6: Guest Access
- **Description**: Verify that a guest can access public pages without logging in.
- **Steps**:
  1. Navigate to the homepage.
  2. Browse public pages (e.g., about, contact).
- **Expected Result**: Guest can view public pages without any authentication prompts.

## Acceptance Criteria
- All test scenarios must pass without any errors.
- Each scenario should be tested in multiple browsers (Chrome, Firefox, Safari).
- Test results should be documented and reviewed by the QA team.
```

### `tests/e2e/test_phase12_feature.py`

```python
import pytest
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.common.keys import Keys

# Fixture to set up and tear down the browser
@pytest.fixture
def browser():
    driver = webdriver.Chrome()
    yield driver
    driver.quit()

def test_user_registration(browser):
    browser.get("http://localhost:3000/register")
    username = browser.find_element(By.NAME, "username")
    email = browser.find_element(By.NAME, "email")
    password = browser.find_element(By.NAME, "password")
    register_button = browser.find_element(By.ID, "register-button")

    username.send_keys("testuser")
    email.send_keys("testuser@example.com")
    password.send_keys("testpassword")
    register_button.click()

    assert "Dashboard" in browser.title
    assert "Registration successful" in browser.page_source

def test_user_login(browser):
    browser.get("http://localhost:3000/login")
    username = browser.find_element(By.NAME, "username")
    password = browser.find_element(By.NAME, "password")
    login_button = browser.find_element(By.ID, "login-button")

    username.send_keys("testuser")
    password.send_keys("testpassword")
    login_button.click()

    assert "Dashboard" in browser.title
    assert "Welcome, testuser" in browser.page_source

def test_user_profile_update(browser):
    browser.get("http://localhost:3000/profile")
    name = browser.find_element(By.NAME, "name")
    email = browser.find_element(By.NAME, "email")
    save_button = browser.find_element(By.ID, "save-button")

    name.clear()
    name.send_keys("Updated Name")
    email.clear()
    email.send_keys("updated@example.com")
    save_button.click()

    assert "Profile updated successfully" in browser.page_source

def test_user_logout(browser):
    browser.get("http://localhost:3000/dashboard")
    logout_button = browser.find_element(By.ID, "logout-button")
    logout_button.click()

    assert "Login" in browser.title
    assert "You have been logged out" in browser.page_source

def test_user_data_deletion(browser):
    browser.get("http://localhost:3000/settings")
    delete_button = browser.find_element(By.ID, "delete-account-button")
    confirm_button = browser.find_element(By.ID, "confirm-delete-button")

    delete_button.click()
    confirm_button.click()

    assert "Register" in browser.title
    assert "Account deleted successfully" in browser.page_source

def test_guest_access(browser):
    browser.get("http://localhost:3000")
    about_link = browser.find_element(By.LINK_TEXT, "About")
    contact_link = browser.find_element(By.LINK_TEXT, "Contact")

    about_link.click()
    assert "About" in browser.title

    browser.get("http://localhost:3000")
    contact_link.click()
    assert "Contact" in browser.title
```
