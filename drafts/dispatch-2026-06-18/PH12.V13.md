## Title: Vapi staging — triage_en SILENT VIP block

### Description
Implement a feature to block VIP users from being processed in the `triage_en` function in the Vapi staging environment. The block should be silent, meaning no error messages or logs should be generated for VIP users.

### File Paths to Create/Modify
- `src/vapi/staging/triage.py`
- `src/vapi/staging/vip_block.py`
- `tests/vapi/staging/test_vip_block.py`

### Function Signatures


#### `src/vapi/staging/vip_block.py`
```python
def is_vip_user(user_id: str) -> bool:
    """
    Check if the user is a VIP user.
    
    Args:
        user_id (str): The unique identifier for the user.
        
    Returns:
        bool: True if the user is a VIP, False otherwise.
    """
    # Example VIP user IDs
    vip_users = ["vip123", "vip456", "vip789"]
    return user_id in vip_users
```

### Acceptance Criteria
1. **VIP User Block**: VIP users (as defined in `vip_block.py`) should be silently blocked from the `triage_en` function, returning an empty dictionary `{}`.
2. **Non-VIP User Processing**: Non-VIP users should be processed as usual by the `triage_en` function.
3. **No Logs or Errors**: No logs or error messages should be generated for VIP users.
4. **Test Coverage**: Unit tests should cover both VIP and non-VIP scenarios.

### Unit Tests
#### `tests/vapi/staging/test_vip_block.py`
```python
import unittest
from vapi.staging.triage import triage_en
from vapi.staging.vip_block import is_vip_user

class TestVIPBlock(unittest.TestCase):
    def test_vip_user(self):
        vip_user_id = "vip123"
        user_data = {
            "name": "VIP User",
            "email": "vip.user@example.com",
            "age": 40,
            "location": "Los Angeles",
            "preferences": {
                "language": "en",
                "notifications": True
            }
        }
        result = triage_en(vip_user_id, user_data)
        self.assertEqual(result, {})

    def test_non_vip_user(self):
        non_vip_user_id = "user123"
        user_data = {
            "name": "Non-VIP User",
            "email": "non.vip.user@example.com",
            "age": 25,
            "location": "San Francisco",
            "preferences": {
                "language": "en",
                "notifications": True
            }
        }
        result = triage_en(non_vip_user_id, user_data)
        self.assertNotEqual(result, {})

if __name__ == '__main__':
    unittest.main()
```
