### kb_writer.py
```python
import requests
from celery import shared_task
from .models import KlaravexKBDraft
from .quality_gate import QualityGate
from .llm_draft import generate_llm_draft
from .topic_picker import pick_topic
from .wp_api import publish_to_wp

@shared_task
def generate_weekly_article():
    topic = pick_topic()
    draft = generate_llm_draft(topic)
    quality_gate = QualityGate(draft)
    if quality_gate.passes():
        draft_entry = KlaravexKBDraft.objects.create(
            topic=topic,
            content=draft,
            status='pending'
        )
        draft_entry.save()
    else:
        # Log or handle quality gate failure
        pass
```

### models.py
```python
from django.db import models

class KlaravexKBDraft(models.Model):
    STATUS_CHOICES = [
        ('pending', 'Pending'),
        ('approved', 'Approved'),
        ('rejected', 'Rejected'),
    ]

    topic = models.CharField(max_length=255)
    content = models.TextField()
    status = models.CharField(max_length=10, choices=STATUS_CHOICES, default='pending')
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)
```

### admin.py
```python
from django.contrib import admin
from .models import KlaravexKBDraft

@admin.register(KlaravexKBDraft)
class KlaravexKBDraftAdmin(admin.ModelAdmin):
    list_display = ('topic', 'status', 'created_at', 'updated_at')
    actions = ['approve_selected']

    def approve_selected(self, request, queryset):
        for draft in queryset:
            if draft.status == 'pending':
                draft.status = 'approved'
                draft.save()
                publish_to_wp(draft)
    approve_selected.short_description = "Approve selected drafts and publish"
```

### static/js/admin/kb_drafts.js
```javascript
function approveDraft(draftId) {
    fetch(`/admin/kb_writer/klaravexkbdraft/${draftId}/approve/`, {
        method: 'POST',
        headers: {
            'X-CSRFToken': getCookie('csrftoken')
        }
    }).then(response => response.json())
      .then(data => {
          if (data.success) {
              location.reload();
          } else {
              alert('Failed to approve draft');
          }
      });
}

function rejectDraft(draftId) {
    fetch(`/admin/kb_writer/klaravexkbdraft/${draftId}/reject/`, {
        method: 'POST',
        headers: {
            'X-CSRFToken': getCookie('csrftoken')
        }
    }).then(response => response.json())
      .then(data => {
          if (data.success) {
              location.reload();
          } else {
              alert('Failed to reject draft');
          }
      });
}

function getCookie(name) {
    let cookieValue = null;
    if (document.cookie && document.cookie !== '') {
        const cookies = document.cookie.split(';');
        for (let i = 0; i < cookies.length; i++) {
            const cookie = cookies[i].trim();
            if (cookie.substring(0, name.length + 1) === (name + '=')) {
                cookieValue = decodeURIComponent(cookie.substring(name.length + 1));
                break;
            }
        }
    }
    return cookieValue;
}
```

## Acceptance Criteria

1. **Weekly Article Generation**: A Celery beat task runs weekly to generate a new article draft.
2. **Topic Picker**: The topic picker selects topics from CVE feed, Klara support themes, SEO gaps, and a manual queue.
3. **LLM Draft Generation**: The LLM generates a draft of 1000-1400 words in the Klaravex voice.
4. **Quality Gate**: The draft passes a quality gate that checks for length, structure, and voice.
5. **Database Entry**: The draft is stored in the `klaravex_kb_drafts` table with a status of 'pending'.
6. **Admin Inbox Approval**: Admins can approve or reject drafts in the Django admin interface.
7. **WP REST API Publish**: On approval, the draft is published to `klaravex.com/kb/` using the WP REST API, with a Higgsfield-generated featured image.
8. **Error Handling**: Proper error handling and logging for failures in any step of the process.
9. **Security**: CSRF protection for admin actions.
10. **Testing**: Unit tests for each component (topic picker, LLM draft generation, quality gate, admin actions, WP API integration).
