# Vendor Evaluation: Dark Web Monitoring for MSP Channel (T-EM-02)

## Evaluation Criteria
1. **MSP Channel Terms**: Partner program structure, margin potential, white-label options  
2. **Atera Integration**: Native integration vs. webhook implementation  
3. **Alert Quality**: False positive rate, actionable intelligence, credential verification  
4. **Monitoring Scope**: Employee email coverage, domain monitoring depth  
5. **Pricing Model**: Per-seat cost, minimum commitments, tiered pricing  
6. **Loki Integration**: Log ingestion compatibility, SIEM interoperability

## Key Findings

### Technical Integration
- **Best Native Atera Support**: Breach Secure Now  
- **SIEM Readiness**: Constella Intelligence provides full Loki/SIEM integration  
- **Credential Verification**: SpyCloud and Constella offer manual credential validation workflows  

### Commercial Considerations
- **Highest Margin**: Breach Secure Now (35%)  
- **Lowest Entry Cost**: Kaseya ID Agent  
- **No Minimums**: SpyCloud (pay-as-you-go API model available)  

### Monitoring Capabilities
- **Broadest Coverage**: Constella (includes pastebin, criminal forums, breached DBs)  
- **Employee-Focused**: Breach Secure Now includes social media monitoring  
- **Automated Remediation**: SpyCloud offers password reset automation
