## 2. Plugin Artifact

Create the file below. **Do not edit `functions.php` directly.**

```bash

```

```php
<?php
/**
 * Plugin Name:  Klaravex CSP Report-Only
 * Description:  Sends Content-Security-Policy-Report-Only header. T14.47
 * Version:      1.0.0
 * Author:       Klaravex Ops
 * License:      Proprietary
 *
 * ROLLBACK: delete this file or set KLARAVEX_CSP_ENABLED to false in wp-config.php
 */

defined( 'ABSPATH' ) || exit;

// Feature flag — set define('KLARAVEX_CSP_ENABLED', false); in wp-config.php to kill instantly
if ( defined( 'KLARAVEX_CSP_ENABLED' ) && KLARAVEX_CSP_ENABLED === false ) {
    return;
}

add_action( 'send_headers', 'klaravex_send_csp_report_only', 1 );

function klaravex_send_csp_report_only(): void {

    // Do not send on admin, login, cron, REST — adjust as needed
    if ( is_admin() || ( defined( 'DOING_CRON' ) && DOING_CRON ) ) {
        return;
    }

    /*
     * ── PHASE 1 (Week 0–2): Baseline — intentionally permissive default-src
     *    so violations surface without breaking anything.
     *    Tighten each directive on a weekly schedule (see §5).
     * ──────────────────────────────────────────────────────────────────────
     */
    $directives = [
        "default-src 'self'",           // baseline — tighten weekly
        "script-src 'self' 'unsafe-inline' 'unsafe-eval'",  // loosen now, tighten in Phase 2
        "style-src 'self' 'unsafe-inline'",
        "img-src 'self' data: https:",
        "font-src 'self' data: https:",
        "connect-src 'self'",
        "media-src 'self'",
        "frame-src 'self'",
        "frame-ancestors 'self'",       // T14.47 required
        "object-src 'none'",            // T14.47 required
        "base-uri 'self'",              // T14.47 required
        "form-action 'self'",
        "report-uri /csp-report-endpoint.php",   // §3 — swap for report-to URI when ready
    ];

    $policy = implode( '; ', $directives );

    // Guard: never send if headers already sent (e.g. early output)
    if ( ! headers_sent() ) {
        header( 'Content-Security-Policy-Report-Only: ' . $policy );
    }
}
```

## 3. CSP Violation Reporting Endpoint

### Option A — Lightweight PHP collector (self-hosted)

```bash
sudo nano /var/www/html/csp-report-endpoint.php
```

```php
<?php
/**
 * CSP Report-Only violation collector — T14.47
 * Logs to /var/log/csp-violations.log (ensure writable by www-data)
 * ROLLBACK: delete this file; violations simply 404 silently.
 */

$log_file = '/var/log/csp-violations.log';
$max_size  = 10 * 1024 * 1024; // 10 MB — rotate if exceeded

if ( $_SERVER['REQUEST_METHOD'] !== 'POST' ) {
    http_response_code( 405 );
    exit;
}

$content_type = $_SERVER['CONTENT_TYPE'] ?? '';
if ( strpos( $content_type, 'application/csp-report' ) === false &&
     strpos( $content_type, 'application/json' ) === false ) {
    http_response_code( 415 );
    exit;
}

$raw  = file_get_contents( 'php://input' );
$data = json_decode( $raw, true );

if ( ! $data || ! isset( $data['csp-report'] ) ) {
    http_response_code( 400 );
    exit;
}

$report = $data['csp-report'];
$entry  = sprintf(
    "[%s] blocked-uri=%s violated-directive=%s document-uri=%s referrer=%s\n",
    gmdate( 'Y-m-d\TH:i:s\Z' ),
    $report['blocked-uri']         ?? 'unknown',
    $report['violated-directive']  ?? 'unknown',
    $report['document-uri']        ?? 'unknown',
    $report['referrer']            ?? ''
);

// Rotate if oversized
if ( file_exists( $log_file ) && filesize( $log_file ) > $max_size ) {
    rename( $log_file, $log_file . '.' . date( 'Ymd-His' ) . '.bak' );
}

file_put_contents( $log_file, $entry, FILE_APPEND | LOCK_EX );
http_response_code( 204 );
```

```bash
sudo chown www-data:www-data /var/log/csp-violations.log

```

## 4. Nginx / Apache Header Verification

```bash
# Verify header is present on live site (run from any machine)
curl -sI https://klaravex.com | grep -i "content-security-policy"

# Expected output:
# content-security-policy-report-only: default-src 'self'; ... frame-ancestors 'self'; object-src 'none'; base-uri 'self'; ...
```

> ⚠️ If Nginx or Apache is **already** setting a `Content-Security-Policy` or `Content-Security-Policy-Report-Only` header via server config, the PHP header will be **ignored or duplicated**. Check:

```bash
# Nginx
grep -r "Content-Security-Policy" /etc/nginx/
# Apache
grep -r "Content-Security-Policy" /etc/apache2/
```

If found, comment out the server-level header and delegate entirely to the plugin.

## 5. Tightening Schedule (Report-Only → Enforced)

> Analyse violation logs before each phase change.

| Week | Action | Key Directive Change |
|---|---|---|
| **0–1** | Deploy Phase 1 (current) | Baseline permissive — collect data |
| **2** | Audit log; identify CDN/font origins | Add approved origins to `script-src`, `style-src`, `font-src` |
| **3** | Remove `'unsafe-eval'` if no violations | `script-src` tightened |
| **4** | Remove `'unsafe-inline'` scripts; add nonce/hash | `script-src` strict |
| **5** | Remove `'unsafe-inline'` styles | `style-src` strict |
| **6** | Validate zero violations for 48 h | Switch header to `Content-Security-Policy` (enforced) |
| **7+** | Monitor enforced CSP; tune as needed | Ongoing |
