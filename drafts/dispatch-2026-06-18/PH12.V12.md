# VIP Backend API Implementation Spec

## Task ID: PH12.V12

### Title: VIP backend /api/v1/vapi/vip_access

### Description
Implement a new endpoint `/api/v1/vapi/vip_access` to manage VIP access. This endpoint should allow the following operations:
- **GET**: Retrieve VIP access status for a user.
- **POST**: Grant or revoke VIP access for a user.

### File Paths to Create/Modify
- `src/api/v1/vapi/vip_access.js`
- `src/models/VIP.js`
- `src/controllers/vip_access.js`
- `src/routes/vip_access.js`
- `src/middlewares/auth.js`
- `src/config/database.js`
- `src/utils/responseHandler.js`
- `test/api/v1/vapi/vip_access.test.js`

### Data Shapes
#### VIP Model
- `userId` (String): Unique identifier for the user.
- `isVIP` (Boolean): Indicates whether the user has VIP access.
- `createdAt` (Date): Timestamp when the VIP status was created.
- `updatedAt` (Date): Timestamp when the VIP status was last updated.

### Function Signatures
#### Models
- `VIP.js`
  - `async function createVIP(userId, isVIP)`: Creates a new VIP entry.
  - `async function getVIP(userId)`: Retrieves VIP status for a user.
  - `async function updateVIP(userId, isVIP)`: Updates VIP status for a user.

#### Controllers
- `vip_access.js`
  - `async function getVIPAccess(req, res)`: Handles GET requests to retrieve VIP access status.
  - `async function updateVIPAccess(req, res)`: Handles POST requests to grant or revoke VIP access.

#### Routes
- `vip_access.js`
  - `router.get('/api/v1/vapi/vip_access', authMiddleware, getVIPAccess)`
  - `router.post('/api/v1/vapi/vip_access', authMiddleware, updateVIPAccess)`

#### Middlewares
- `auth.js`
  - `function authMiddleware(req, res, next)`: Authenticates the user and checks permissions.

#### Utils
- `responseHandler.js`
  - `function sendSuccessResponse(res, data, message)`: Sends a success response.
  - `function sendErrorResponse(res, error, message)`: Sends an error response.

### Acceptance Criteria
1. **GET /api/v1/vapi/vip_access**
   - **Input**: User ID in the request query.
   - **Output**: JSON response with VIP status.
   - **Example Response**:
     ```json
     {
       "userId": "12345",
       "isVIP": true
     }
     ```
   - **Error Handling**:
     - If the user ID is invalid or not found, return a 404 error.
     - If there is an internal server error, return a 500 error.

2. **POST /api/v1/vapi/vip_access**
   - **Input**: User ID and VIP status (`true` or `false`) in the request body.
   - **Output**: JSON response indicating the success of the operation.
   - **Example Response**:
     ```json
     {
       "message": "VIP access updated successfully"
     }
     ```
   - **Error Handling**:
     - If the user ID is invalid or not found, return a 404 error.
     - If the VIP status is invalid, return a 400 error.
     - If there is an internal server error, return a 500 error.
