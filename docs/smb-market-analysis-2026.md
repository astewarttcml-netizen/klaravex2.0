# Klaravex — SMB Market Analysis & Service-Fit Review 2026
**Saved:** 2026-06-03 · Source: 04-SMB-Market-Analysis companion doc

## TL;DR
Current catalog: strong on cloud + infrastructure, genuinely differentiated on AI (Loki).
Critical gap: underweight on managed security operations (MDR/EDR/awareness/cyber-insurance readiness) — which is exactly where 2026 SMB money is moving.

## Key numbers to remember
- Cyber security is fastest-growing MSP segment: ~18%/yr
- 71% of SMBs now use MDR/managed SOC
- 73% of SMBs FAIL cyber-insurance assessments in 2026
- 96% of MSPs report high/moderate vCISO demand
- Market pricing: $125–300/user/mo (Klaravex tiers are at or below market)

## Service verdict (see full doc for detail)
- ⭐ Lead-with: AI/Loki, Directive tier (compliance+vCISO), M365 identity/security
- ✅ Sell: Security Audit (use as front door), Backup/DR, Azure, AWS, GWS, Intune
- 🔁 Table-stakes: Remote IT, monitoring (Loki+Atera deliver)
- 🧱 Commodity/de-emphasize: Procurement, standalone PowerShell, legacy server/virtualization

## Gaps to close (in priority order)
1. MDR / Managed Detection & Response (white-label: Blackpoint, Huntress, SentinelOne)
2. EDR as a managed line (resell Huntress/SentinelOne/Defender for Business)
3. Cyber-Insurance Readiness Assessment (fixed-fee → remediation retainer)
4. Security Awareness Training + phishing sim (resell KnowBe4/Hook/usecure)
5. Email security / anti-phishing (add to M365/GWS hardening)
6. Co-Managed IT offering (augment in-house IT person, 100–200 employee segment)
7. vCISO (distinct from vCIO — split out in Directive tier)
