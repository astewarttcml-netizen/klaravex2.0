# POC → production flip

**Date:** 2026-08-22  
**Operator:** Anthony approved

## Change

`growth/.env`:

```bash
GROWTH_POC_MODE=false
GROWTH_POC_FAST=false
```

Growth API restarted (`growth-api.service`).

## What changes

| Path | Before (POC) | After (production) |
|------|--------------|-------------------|
| **leads** research | Fixture copy from `data/poc/leads/` | Live pre-enrichment via klaravex worker pipeline |
| **Charter runs** | `GROWTH_POC_FAST` stub outbox in seconds | Full Claude executor (`GROWTH_EXECUTOR_TIMEOUT_S=7200`) |
| **Stream prompts** | Injected `data/poc/streams/*/context.md` | Charter inputs + live outbox history only |
| **Adapters** | `poc_sandbox` samples | `ready` / `stub` (live I/O still per-adapter implementation) |
