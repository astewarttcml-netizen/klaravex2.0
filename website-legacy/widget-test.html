Quick-reply actions

Acceptance:

  • Each pill renders with the brand cyan border.
  • send:<text> pre-fills the input and immediately sends.
  • url:<href> opens the URL in a new tab on desktop, navigates same-tab on mobile.
  • intake:<sku> navigates to /contact/?sku=<sku> (or /de/kontakt/?sku=… on .de).

Locale

Acceptance for L11/L17:

  • Without override: the locale matches the hostname (en on all klaravex.com surfaces).
  • GDPR text links to the correct privacy URL for the locale.
  • Placeholder, send/close labels, error message all in the right language.

Error surfacing (regression test for the L5 root cause)

Acceptance:

  • The 12-second AbortController timeout fires.
  • The widget surfaces cfg.errorMsg in the chat ("Sorry, there was a technical error…") instead of the old canned "Thank you for your message. We'll be in touch shortly."
  • The DevTools console logs [KvxChat] Error: … with the underlying error.
