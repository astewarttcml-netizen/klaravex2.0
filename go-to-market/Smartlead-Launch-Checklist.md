# Smartlead.ai — Launch Checklist (protect deliverability)
1. SENDING DOMAIN (do NOT use klaravex.com/.de): buy a secondary (getklaravex.com / tryklaravex.com). Set up SPF, DKIM, DMARC, and a redirect to klaravex.com.
2. MAILBOXES: create 2–3 inboxes on that domain (Google Workspace or MS365). Connect all to Smartlead.
3. WARMUP: turn on Smartlead warmup for ALL mailboxes. Wait ~2–3 weeks before real sends.
4. RAMP: start 10–15/day per mailbox, +5/day weekly up to ~30–40. 3 mailboxes ≈ 30–60/day = ~50/week target.
5. SENDING WINDOW: Tue–Thu, 8–11am recipient local time. Skip Mon/Fri.
6. CONTENT: email #1 has NO links (or one plain link max), plain-text style, spintax ON, real signature + physical address + unsubscribe (CAN-SPAM).
7. STOP-ON-REPLY: ON. Bounce/spam guard: ON. Keep bounce rate <3%, open via SmartDelivery test first.
8. CAMPAIGNS: 3 → Bookkeeper (cold email), Insurance Broker (cold email), Steuerberater (LinkedIn only).
9. MASTER INBOX: check daily; on any positive reply → book the free Assessment (your risk scorecard) → that's the conversion.
10. TRACK: reply rate + positive-reply rate by segment weekly; double down on the winner, kill the loser.
