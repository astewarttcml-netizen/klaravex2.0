Known automation gaps (2026-07-19 session)
--------------------------------------------
Tried to push the profile-picture update automatically via API for
Twitter and Facebook — both failed on missing permissions, not a code bug:
  - Twitter: 401 on POST /1.1/account/update_profile_image.json — this
    endpoint needs broader account-level API access than the current
    tweet-posting token has.
  - Facebook: 400, explicitly "Requires pages_manage_metadata permission"
    — different scope than the pages_manage_posts scope already granted.
  - LinkedIn Company logo update wasn't attempted — likely needs
    Community Management API access this app doesn't have either.
All three need you to re-authorize the app with expanded scopes through
each platform's own OAuth consent flow — not something I can grant to an
existing token. Once re-authorized, the same code path used for posting
(app/services/social_publisher.py) can be extended to push these
automatically in the future.
